Aphasia examples — binary classifier & severity regression (voxel space, covariate-aware)¶

Two worked examples matching a common clinical setup, at 4 mm and controlling for age + sex:

  1. Binary classifier — aphasia: yes / no (a binary deficit).
  2. Severity regression — a continuous aphasia-severity score.

For each we recover the neural substrate with all four methods — VLSM, SVR-LSM, the MLP-VAE, and the conv-VAE (3D-convolutional) — each run covariate-blind vs covariate-aware (age + sex as nuisance covariates, standard partialing-out control). The conv-VAE is the strongest recoverer and the one covariate-awareness reliably helps.

Resolution — why 4 mm here. With cohorts in the hundreds and no per-voxel ground truth, the binding constraint is statistical power per voxel. 4 mm gives a few thousand well-covered voxels (good power, little overfitting, tractable). 2 mm (~200k voxels) with N in the hundreds is underpowered per test and overfit-prone — worthwhile only as a refinement once 4 mm works, and then with aggressive coverage-restriction and the conv-VAE (whose spatial prior is what makes higher resolution viable). Start at 4 mm; escalate to 2 mm later.

The conv-VAE is GPU-trained, so its maps here are precomputed on a shipped 4 mm sample; the fast methods (VLSM / SVR-LSM / MLP-VAE) run live at the end so you can see the exact API to plug your data into. Aphasia → the NeuroQuery language substrate is the ground truth in these demos.

How the precomputed maps are scored¶

Each GPU run saved, per method and per mode (blind/aware), a continuous score map and the method's self-thresholded mask. We score them exactly as for the live methods: Dice@k (top-|M| ranking), binary Dice (the mask vs truth), and leakage (how much off-target weight tracks the age confound — lower is better).

def score_maps(npz_path, task_key):
    """Load a saved-maps npz and score every method x {blind,aware} for `SUB`."""
    z = dict(np.load(npz_path, allow_pickle=False))
    out = {meth: {} for meth in METHODS}
    for meth in METHODS:
        for mode in ("blind", "aware"):
            s = z[f"{SUB}|{task_key}|{meth}|{mode}|score"].astype(np.float64)
            mask = z[f"{SUB}|{task_key}|{meth}|{mode}|mask"].astype(bool)
            out[meth][mode] = {"dice_k": dice_at_k(s, m, k), "dice_bin": dice(mask, m),
                               "leak": leakage(s, m, exposure), "score": s, "mask": mask}
    return out

def show_table(res, title):
    print(f"{title}\n{'method':10s}" +
          "".join(f"{x:>9s}" for x in ("Dk_bl","Dk_aw","bin_bl","bin_aw","leak_bl","leak_aw")))
    for meth in METHODS:
        b, a = res[meth]["blind"], res[meth]["aware"]
        print(f"{meth:10s}{b['dice_k']:>9.3f}{a['dice_k']:>9.3f}{b['dice_bin']:>9.3f}"
              f"{a['dice_bin']:>9.3f}{b['leak']:>9.3f}{a['leak']:>9.3f}")

Does higher resolution help? — 4 mm vs 2 mm¶

James asked whether to stay at 4 mm or move to 2 mm. We ran the identical pipeline at 2 mm (src/scripts/aphasia_2mm.py — one line of resolution config different) on the same 512 lesions. The coverage-restricted analysis grid grows from V_cov = 2 541 → 20 542 voxels (~8× finer), so 2 mm needs a GPU and more epochs. Below: the conv-VAE (covariate-aware, the best method above) at both resolutions, on each task. Read-out — finer voxels are not automatically better. Going to 2 mm helped the severity regression (Dice@k 0.69 → 0.74, and it cut confound leakage 0.40 → 0.29) but hurt the binary classifier (0.64 → 0.54). Splitting the same cohort across ~8× more voxels leaves less statistical power per voxel, and the information-poorer yes/no label feels that most; the richer continuous severity signal has enough information to exploit the finer grid.

Recommendation for James's cohorts (488 binary, 255 severity — hundreds of cases): start at 4 mm for both. It is the cheaper, higher-power default and it won the binary task here. Treat 2 mm as a refinement to try once 4 mm looks solid and a GPU is available — most promising for the severity outcome, and worth re-checking on his own N, since 2 mm's appetite for data grows as the voxels shrink (the 255-case severity cohort is the smaller one, so validate before trusting a 2 mm gain there).

Plug in your own data / run it live¶

Everything is just X (an N × V lesion-overlap matrix), y (your label), and cov (an N × d covariate matrix, e.g. [age, sex]). Blind = omit cov; aware = pass it.

# binary classifier (aphasia yes/no)

conv = conv_vae.fit_conv_vae(X, severity, mask_idx=mask_idx, vol_shape=vol_shape, cov=cov,
                             continuous=True, epochs=300)
mlp  = fit_parcel_vae(X, severity, cov=cov, continuous=True, epochs=500)

Takeaways for these tasks¶

  • Conv-VAE first. The 3D spatial prior makes it the strongest substrate recoverer for both a binary classifier and a continuous-severity outcome, and it is the method covariate-awareness reliably helps (best recovery + lowest confound leakage). The classical methods over-correct when age is collinear with lesion volume.
  • Covariates via partialing-out, entered as cov=[age, sex]; the VAEs route them to the deficit head only, so the substrate map stays covariate-invariant.
  • Severity = continuous=True on the VAEs (MSE head); VLSM/SVR take the continuous target directly.
  • Start at 4 mm; treat 2 mm as a task-dependent refinement. In the 4 mm-vs-2 mm test above, the finer grid helped severity (Dice@k 0.69 → 0.74) but hurt the binary classifier (0.64 → 0.54) — higher resolution is not automatically better when N is in the hundreds. Same code either way (aphasia_4mm.py / aphasia_2mm.py); the conv-VAE is the method to carry to higher resolution.
