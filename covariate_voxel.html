Covariate-aware substrate recovery in voxel space — a convolutional VAE¶

Lesion–symptom mapping asks which regions, when damaged, cause a deficit — the neural substrate. This tutorial works in 4 mm MNI voxel space and compares four recovery methods:

  • VLSM — mass-univariate Welch t-test + permutation FDR.
  • SVR-LSM — multivariate RBF support-vector regression + back-projection (Zhang 2014).
  • MLP-VAE — the two-arm variational auto-encoder of vae_lesion_deficit (membership × importance).
  • Conv-VAE — the same two-arm VAE with a 3D-convolutional encoder/decoder (spatial prior).

Real deficits also depend on covariates (age, …) that are confounded with the lesion (older patients tend to have larger lesions), so each method is run covariate-blind vs covariate-aware. Two headline findings, on 512 real KCH stroke lesions:

  1. The conv-VAE recovers the substrate best — the 3D spatial prior beats the flat MLP and the classical methods.
  2. Covariate-awareness helps the conv-VAE (and it leaks the least confound bias), whereas the linear methods over-correct.

The heavy conv-VAE is trained on a GPU; its numbers here are precomputed (voxel_results.json), while the fast methods run live below. Model/baseline logic lives in importable modules (voxel_data.py, baselines.py, mlp_vae.py, conv_vae.py, covariate_deficits.py).

2. The four methods¶

All four return a per-voxel score and a self-thresholded mask. Covariate control:

  • VLSM / SVR-LSM — partialing-out: the behaviour is residualized on [1, covariates] before the test/fit (the DeMarco & Turkeltaub 2018 standard; appending covariates as SVR features is mis-scaled and inert — see the note in baselines.py).
  • VAEs — a covariate head (β main + γ interaction) added to the deficit predictor; the covariates enter the head only, never the encoder, so the substrate readout E[σ(γ)·w] stays covariate-invariant.

The conv-VAE swaps the flat MLP for a 3D-conv encoder/decoder (CoordConv, label-as-volume, downsample/upsample blocks) — the spatial prior is what voxel space needed:

3. The covariate-conditioned deficit¶

make_covariate_benchmark_deficits builds severity = g·clip(1+β_int·age) + β_main·age, with age constructed so corr(age, lesion_volume) ≈ ρ — the lesion-volume confound expressed through age. Positives are the top target_rate by severity.

4. Blind vs aware — the fast methods, live¶

VLSM, SVR-LSM and the MLP-VAE run live on one substrate (the conv-VAE is precomputed in §5). We score Dice@k (top-|M| ranking), binary Dice (self-thresholded mask), and leakage (how much off-target weight tracks the age confound; lower = less biased).

In [5]:
RULE = "coverage"
y = deficits[RULE]
k = int(m.sum())
exposure = age_exposure(data.X, cov)

def run(method, cov_arg):
    if method == "vlsm":
        mask = vlsm_binary(data.X, y, delta=0.10, n_perm=N_PERM, cov=cov_arg, seed=SEED)[0]
        score = vlsm_stat(data.X, y, delta=0.10, cov=cov_arg)
    elif method == "svr":
        mask = svr_binary(data.X, y, n_perm=N_PERM, cov=cov_arg, seed=SEED)[0]
        score = svr_weights(data.X, y, cov=cov_arg)
    else:
        score = fit_parcel_vae(data.X, y, cov=cov_arg, epochs=VAE_EPOCHS, seed=SEED)
        mask = focal_mass_mask(score)
    return score, mask

7. Takeaways¶

  • The 3D spatial prior wins. The conv-VAE is the best recoverer in voxel space — Dice@k 0.456 and binary Dice 0.420 blind, beating the flat MLP-VAE (0.376 / 0.366) and the classical methods. Locality + parameter-sharing is what the flat MLP lacked.
  • Covariate-awareness helps the conv-VAE (Dice@k 0.438→0.465, binary 0.334→0.373) and it leaks the least confound bias (0.140→0.057). The linear methods over-correct: VLSM's leakage rises (0.404→0.564), SVR trades ranking for deployment — because residualizing an age that is collinear with lesion volume also strips substrate signal (a mass-univariate can't disentangle them; the multivariate/latent methods can).
  • Do covariate control the standard way — partial out the behaviour, don't append covariates as features (mis-scaled and inert).
